# Tic-Tac-Toe Game (C# Desktop App)

## 🎯 Overview
This is a **Tic-Tac-Toe** game implemented as a **desktop application in C#** using **Windows Forms**.  
It allows two players to play locally on the same computer, with automatic detection of wins, draws, and turn management.

## 🏗️ Features
- **Two-player local gameplay**  
- **Win detection** for rows, columns, and diagonals  
- **Draw detection** when the board is full  
- **Restart button** to reset the game  
- **Simple and intuitive UI** using Windows Forms  

## 🛠️ Technologies
- C#  
- .NET Framework / .NET 6+  
- Windows Forms (WinForms)

## 🎮 How to Play
1. Launch the application.  
2. Player 1 starts by clicking on an empty cell.  
3. Player 2 takes their turn.  
4. The game announces the winner.  
5. Click **Restart** to play again.
